## 🔍 Systematic NOC Troubleshooting Methodology

When diagnosing enterprise outages, I employ a structured **OSI Layer 1-through-7 methodology**:

```text
  ┌─────────────┐
  │ Layer 7 / 4 │ --> DNS resolution (nslookup/dig), TCP port testing, ACL rule hit counters
  ├─────────────┤
  │ Layer 3     │ --> Routing table inspection (show ip route), ICMP ping, traceroute, MTU checks
  ├─────────────┤
  │ Layer 2     │ --> VLAN assignment, 802.1Q trunk state, STP root consistency, Port Security err-disable
  ├─────────────┤
  │ Layer 1     │ --> Physical link state (show ip int bri), SFP transceiver levels, cable continuity
  └─────────────┘
```
